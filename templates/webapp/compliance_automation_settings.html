What each run does

  • Sends policy-governed deadline reminders and escalations.
  • Creates duplicate-safe evidence renewal requests.
  • Creates scheduled and expired-evidence reassessment work.
  • Processes risk reviews and acceptance expiration only where optional risk is enabled.

Omni does not contain a permanent background process. Invoke the runner daily from Windows Task Scheduler; Omni decides which enabled organizations are due.

.venv\Scripts\python.exe manage.py run_compliance_automation

The scheduled task should start in the private Omni project directory. No password or client file belongs in the task arguments.
