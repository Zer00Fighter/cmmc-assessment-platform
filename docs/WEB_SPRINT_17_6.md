# Sprint 17.6 — Authoritative Source Registry

Sprint 17.6 privately imports the CCF authoritative-document workbook as framework provenance, not client evidence. Each record preserves locale, exact CCF header, ADI, publisher, formal name, official URL, quality, source row, filename, and SHA-256. Exact headers link to external authorities. Reports can cite linked official publications. Missing URLs, invalid URLs, duplicate ADIs, and excluded footer rows remain explicit quality outcomes; future Sprint 18 monitoring can check source availability and version changes.
