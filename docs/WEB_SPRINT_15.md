# Sprint 15 — Shared evidence and testing workspace

Sprint 15 provides one assessor workspace for mapped work while preserving independent framework conclusions. It includes unified reuse candidates, evidence applicability decisions, consolidated evidence requests, evidence freshness/supersession, test reuse by reference, and a framework-specific remaining-work queue.

Only accepted evidence may be reused. Applicability is decided per target control with rationale and limitations. Test executions are referenced rather than copied, and no mapped control or objective outcome is propagated automatically.
