# Sprint 18.3 — Comprehensive User and Administrator Manual

Sprint 18.3 publishes a reproducible Word manual for Omni's implemented web
application through Sprint 18.2.

## Deliverables

- `Omni-Comprehensive-User-and-Administrator-Manual.docx`
- `scripts/build_omni_manual.py`, the deterministic public manual builder
- Framework-agnostic lifecycle diagram in the Introduction
- Role-based guidance for assessors, control owners, reviewers, organization
  administrators, framework administrators, and platform administrators
- End-to-end procedures for assessment planning, objective and control result
  entry, evidence, remediation, quality review, sign-off, multi-framework reuse,
  optional risk management, reporting, notifications, imports, mapping
  governance, backups, security, and troubleshooting

## Terminology boundary

The manual uses universal GRC terminology. Framework-native identifiers,
objectives, scoring, and reporting remain specific to the framework selected in
an assessment. Framework-specific terms are presented only as aliases or
examples and are not treated as Omni's universal operating model.

## Public-repository boundary

The manual and its diagram contain synthetic product guidance only. They do not
contain organization records, client data, evidence, credentials, private
source workbooks, or local database content.
